# Programação Web

## Aulas de Programação Web - 2026

Repositório de atividades da disciplina de Programação Web do IFSP Campus Boituva.

## Tópicos Aprendidos na Aula 2

- Versionamento com Git
- Criação e clonagem de repositórios
- Fork de repositórios
- Sparse Checkout
- Comandos: git clone, git add, git commit, git push

## Comando Git mais usado hoje

```bash
git add .
git commit -m "mensagem"
git push origin main
```
